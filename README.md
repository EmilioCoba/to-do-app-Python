# Flask To-Do List

A simple To-Do List web application built with Flask, Flask-SQLAlchemy, SQLite, Flask-WTF, and Bootstrap.

## Features

* View all tasks
* Add new tasks
* Edit existing tasks
* Mark tasks as complete or incomplete
* Delete tasks
* Store tasks in an SQLite database

## Technologies

* Python
* Flask
* Flask-SQLAlchemy
* SQLite
* Flask-WTF
* Bootstrap 5
